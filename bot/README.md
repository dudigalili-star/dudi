# בוט טלגרם — שרטוטים לספק

שולחים לבוט **תמונה** של חלק או של סקיצה, או **תיאור בטקסט**, ומקבלים:

- שרטוט מסודר: תמונה בצ'אט, וקובץ PDF בלחיצת כפתור
- לחלקים מורכבים גם STEP ו-DXF
- מייל מוכן לספק, יחד עם ZIP של כל הקבצים

התיקונים נעשים בהודעה רגילה, למשל: _"האורך 260, חומר 1045, כמות 20"_.

הבוט משתמש באותו קוד כמו אפליקציית הווב (`parts-app/core`), כך שהשרטוטים יוצאים זהים.

## פקודות

| פקודה | מה עושה |
|---|---|
| (תמונה / כמה תמונות ביחד) | חלק חדש. הכיתוב של התמונה נשלח ל-AI כמידע נוסף |
| (הודעת טקסט) | תיקון של החלק האחרון. אם עדיין אין חלק, נוצר חלק חדש מהתיאור |
| `/new` | החלק הבא שתתאר בטקסט ייפתח כחלק חדש (או `/new פין קוטר 20 אורך 100`) |
| `/list` | כל החלקים בבקשה, ובחירת חלק לתיקון |
| `/email` | ZIP עם כל הקבצים ומייל מוכן, כולל כפתור "פתח טיוטה ב-Gmail" |
| `/clear` | התחלת בקשה חדשה |

## הקמה (פעם אחת)

### 1. יצירת הבוט בטלגרם
1. בטלגרם פתח את **@BotFather** ושלח `/newbot`.
2. בחר שם ושם משתמש לבוט.
3. קבל את ה-**token** (נראה כמו `123456789:AA...`) ושמור אותו.

### 2. מפתח של Anthropic (Claude)
1. היכנס ל-https://platform.claude.com/settings/keys.
2. צור מפתח (`sk-ant-...`).
3. ודא שיש קרדיט בחשבון.

### 3. הרצה על שרת חינמי (Oracle Cloud)
על שרת Ubuntu (למשל Oracle Always Free), אחרי התחברות ב-SSH, מריצים פקודה אחת:
```bash
curl -fsSL https://raw.githubusercontent.com/dudigalili-star/dudi/main/bot/deploy/install.sh | sudo bash
```
הסקריפט עושה את הכל:
- מתקין את Node.js ואת הבוט
- שואל את הטוקן ואת המפתח (הם לא מוצגים על המסך)
- מגדיר את הבוט כשירות שעולה לבד אחרי הפעלה מחדש של השרת

להוספת משתמשים מורשים: אותה פקודה עם `-s -- --users 12345678`.
לצפייה בלוגים: `sudo journalctl -u parts-bot -f`.

**עדכונים — אוטומטיים, בלי טרמינל:**
- **כל לילה:** בסביבות 03:30 השרת מושך מ-GitHub את מה שמוזג ל-`main` ומפעיל את הבוט מחדש. הבוט שולח הודעה עם תיאור השינוי.
- **`/update` בטלגרם:** מעדכן מיד.
- **`/version` בטלגרם:** מראה איזו גרסה רצה עכשיו.
- **אם גרסה חדשה לא עולה:** השרת חוזר לבד לגרסה הקודמת ומודיע על כך בטלגרם.
- **שינוי בסקריפט ההתקנה עצמו:** ההתקנה רצה מחדש אוטומטית, בלי לשאול שום דבר. ההגדרות השמורות לא נמחקות, גם אם הרשת נופלת באמצע.

איך זה עובד:
- `bot/deploy/update.sh` מבצע את העדכון, ומורץ על ידי systemd.
- `parts-bot-update.timer` מפעיל אותו כל לילה.
- `parts-bot-update.path` מפעיל אותו כשהבוט יוצר את הקובץ `update-request`.

### 3ב. הרצה בשירות ענן אחר
הבוט צריך לרוץ כל הזמן. האפשרות הפשוטה היא שירות ענן שמריץ Docker ישירות מה-GitHub. ב-Railway, Render (Background Worker) או Fly.io:

1. צור פרויקט חדש מהריפו `dudigalili-star/dudi`. ה-`Dockerfile` שבשורש הריפו מגדיר את הבוט.
2. הגדר את משתני הסביבה (בטבלה למטה).
3. חבר **Volume** לנתיב `/data`, כדי שהבקשות יישמרו גם אחרי הפעלה מחדש.

**אפשרות אחרת — מחשב שלך** (Node.js 20 ומעלה):
```bash
cd bot
npm install
TELEGRAM_BOT_TOKEN=... ANTHROPIC_API_KEY=... ALLOWED_USERS=... npm start
```

### 4. בעלות ומפתח — מטלגרם
- שולחים לבוט `/start`.
- **מי שכותב ראשון הופך לבעלים**, ואף אחד אחר לא יכול להשתמש בבוט.
- אם המפתח של Claude לא הוזן בהתקנה, הבוט מבקש אותו: מדביקים את המפתח (`sk-ant-...`) כהודעה. הבוט בודק אותו, שומר אותו בשרת ומוחק את ההודעה מהצ'אט.
- להחלפת המפתח: שולחים מפתח חדש באותה דרך.
