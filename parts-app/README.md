# שרטוטים לספק — אפליקציה

אפליקציית ווב עצמאית שאפשר להתקין על הטלפון או המחשב (PWA). היא הופכת צילום, סקיצה או תיאור בטקסט של חלק לשרטוט מוכן לשליחה לספק: PDF, ולחלקים מורכבים גם STEP ו-DXF. בנוסף היא מכינה מייל לבקשת הצעת מחיר.

יש גם **בוט טלגרם** שעובד עם אותו קוד — ראה [`../bot/README.md`](../bot/README.md).

## שימוש
1. **חלק חדש:** מעלים תמונה אחת או כמה, או כותבים תיאור, ולוחצים "נתח עם AI".
2. **בדיקה:** עוברים על המידות, על השאלות הפתוחות ועל המידות שהוערכו. אפשר לתקן בטופס או במשפט חופשי ("האורך 260").
3. **קבצים:** מורידים PDF, STEP או DXF. כפתור "כל הקבצים (ZIP)" מכין גם את המייל לספק.

**התקנה:**
- **אנדרואיד / כרום:** כפתור "📲 התקנה" בראש העמוד. אחרי ההתקנה אפשר לשתף תמונה מהגלריה ישירות לאפליקציה.
- **אייפון:** בספארי, שיתוף ← "הוסף למסך הבית".

## אירוח
העמוד צריך לרוץ מכתובת אינטרנט, לא מקובץ מקומי. הדרך הפשוטה היא GitHub Pages:
1. בהגדרות הריפו: Settings ← Pages ← Deploy from a branch ← `main` / root.
2. האפליקציה תהיה בכתובת `https://dudigalili-star.github.io/dudi/parts-app/`.

## מבנה

| נתיב | תוכן |
|---|---|
| `index.html`, `app.js` | ממשק המשתמש |
| `sw.js`, `manifest.webmanifest`, `icons/` | התקנה, עבודה בלי רשת ושיתוף תמונות לאפליקציה |
| `core/` | הלוגיקה, משותפת לאפליקציה ולבוט (פירוט למטה) |
| `vendor/` | jsPDF, JSZip, Anthropic SDK ו-replicad/OpenCascade, ארוזים מראש |

הקבצים ב-`core/`:
- `model.js` — מבנה החלק
- `drawing.js` — השרטוט
- `render.js` — יצוא ל-SVG, PDF ו-DXF
- `cad.js` — יצירת STEP
- `ai.js` — Claude
- `email.js` — טקסט המייל

## פרטים
- כל חלק נשמר כמפרט JSON אחד. השרטוט, המודל התלת-ממדי, ה-DXF והמייל נוצרים כולם ממנו, כך שאין סתירות ביניהם.
- הנתונים ומפתח ה-API נשמרים רק בדפדפן.
- מנוע ה-CAD שוקל כ-23MB ונטען רק כשמבקשים קובץ STEP.
